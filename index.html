Records it speaks

As of February 13, 2026, is-not.cool supports A, AAAA, CNAME, MX, TXT, NS, SRV and DS records — so it can point at whatever you are already hosting.

How it works

is-not.cool is powered by DNSControl and Cloudflare, which means records are made through the GitHub repository — reviewed like code, deployed like code.

  1. 01

    Read the rules

    Start with the terms of service and the README in the registration repository.

  2. 02

    Add your record

    Fork the repository and add the record for the subdomain you want, following the examples already there.

  3. 03

    Open a pull request

    Once a maintainer merges it, DNSControl pushes the record to Cloudflare and the subdomain goes live.

Say hello

Questions about a record or a rejected pull request? Email the maintainers or open an issue in the registration repo.
